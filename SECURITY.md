# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Until a dedicated security mailbox is published, use GitHub private vulnerability reporting for this repository.

Include the affected version, reproduction steps, impact and any suggested mitigation. Maintainers will acknowledge a valid report within five business days and coordinate disclosure after a fix is available.

Only the latest minor release receives security fixes during the pre-1.0 period. The supported-version policy will be expanded before v1.0.

The product threat model and engineering controls are documented in [`docs/SECURITY.md`](docs/SECURITY.md).
